# D1 — Deadline-enforced escrow

## SOW commitment

Add a settlement deadline and a permissionless `claim_refund_after_deadline()` path for a tournament that has neither been finalized nor cancelled. The SOW also requires failure-path testing before the deadline.

## Traceability

| SOW criterion | Implementation/evidence source | Status rule |
| --- | --- | --- |
| Refund succeeds after the deadline | [Issue #218 evidence](https://github.com/webnxt-2030/ggg/blob/develop/docs/verification/issue-218-testnet-evidence.md) | Mark Testnet verified only when an explorer transaction proves the post-deadline refund. |
| Refund fails before the deadline | [Issue #218 evidence](https://github.com/webnxt-2030/ggg/blob/develop/docs/verification/issue-218-testnet-evidence.md) | Passing contract test evidence supports local verification. |
| Contract tests cover both paths | [Regression evidence](https://github.com/webnxt-2030/ggg/blob/develop/docs/verification/issue-221-regression-evidence.md) | Keep the recorded command output or CI link with the result. |

## Evidence gap check

The final reviewer package should identify the specific Testnet refund transaction and contract instance. Do not substitute a build, a WASM upload, or a unit-test result for that live acceptance evidence.
