# D3 — SDK extraction, npm, and live redeploy

## SOW commitment

Extract the contract client, transaction builders, and validation helpers into a standalone package; publish `@goodgameguild/escrow-sdk@0.1.0`; provide a Node.js example and public usage documentation; and redeploy the Testnet application as the reference consumer.

## Status

**Completed and independently Testnet verified on 24 September 2026.** The public package, immutable source, standalone example, SDK-backed deployment, health endpoint, demo, and three live terminal paths are recorded below.
