# D3 — SDK extraction, npm, and live redeploy

## SOW commitment

Extract the contract client, transaction builders, and validation helpers into a standalone package; publish `@goodgameguild/escrow-sdk@0.1.0`; provide a Node.js example and public usage documentation; and redeploy the Testnet application as the reference consumer.

## Required proof

| Requirement | Evidence needed |
| --- | --- |
| Published SDK | Public npm package URL and installed version |
| Reusable source | Public repository/package source and installation/usage documentation |
| Example | Node.js example that runs against the published package |
| Reference consumer | Redeployed application URL with a public health check |
| End-to-end validation | Testnet create → join → settle → payout proof |

## Current status

**Planned.** The approved SOW defines this deliverable, but this book does not claim an npm publication, completed example, or matching live redeploy until public evidence is added.

## Completion checklist

To move D3 from Planned to Completed, add the public npm URL and installed version, the public SDK source/README, a repeatable Node.js example result, the redeployed app and health-check response, a public demo video showing the full flow on that redeployed Testnet app, and the transaction trail for the Testnet end-to-end flow. The public application endpoints are listed on the book landing page, but their availability is not evidence that they are using the D3 SDK or a matching updated escrow artifact.
