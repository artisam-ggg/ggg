# GGG — Good Game Guild

Every paid competitive-gaming event has the same broken step: between "entry fees collected" and "winners paid," a human custodian — an organiser, a Discord admin, a third-party platform — has to hold the pot, and that person can skim it, stall the payout, or vanish. GGG removes the custodian entirely. Each tournament deploys its own Soroban smart contract on Stellar; players pay the entry fee (XLM or USDC) straight into the contract from their own wallet with no account required, a referee submits the final standings, and the **contract itself** pays the winners in a single on-chain transaction. There is no withdraw function — money leaves escrow only as a winner payout or a refund, and every registration, payout, and refund is a public, independently verifiable Stellar transaction. For Stellar, GGG is a concrete, non-DeFi consumer use case for Soroban: it turns a real trust problem across millions of grassroots and community tournaments into recurring on-chain volume — contract deployments, entry-fee payments, and multi-payout settlements — while giving both XLM and Circle's USDC-on-Stellar a natural, repeatable consumer flow.

**For reviewers:** GGG is a working build verified against Stellar **Testnet**, where every acceptance criterion passes. The escrow smart contract ships with a full suite of unit tests, and the platform pairs a responsive web app with a background event subscriber that streams live prize-pool and participant updates in real time. A design principle worth noting: **the server never holds a private key** — it only builds, simulates, submits, and reads transactions, while all signing happens client-side in the user's Freighter wallet, making GGG a reusable reference for the "client signs, server never holds keys" pattern. The included pitch deck offers a sub-two-minute demo walkthrough and the full product story. Two notes to set expectations: no public deployment is live yet, and while USDC support is fully built, it is gated behind per-network configuration — so the default demo path is XLM on Testnet.
